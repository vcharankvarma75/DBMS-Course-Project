# Car Rental Reservation and Vehicle Return Management System

## 1. Project Overview

The **Car Rental Reservation and Vehicle Return Management System** is a DBMS course project designed to manage vehicle information, customer records, car reservations, rental transactions, and vehicle returns.

The system aims to simplify car rental operations by organizing data in a relational database and providing a user interface for managing rental activities.

## 2. Objectives

- To design and implement a relational database for car rental operations.
- To manage vehicle and customer records efficiently.
- To create and manage car rental reservations.
- To record vehicle pickup and return details.
- To calculate rental charges and applicable late fees.
- To demonstrate SQL operations, joins, aggregate functions, and database constraints.
- To maintain accurate and consistent rental records.

## 7. Setup and Execution

### Prerequisites

Install the software required by the actual implementation, such as Python, MySQL Server and a web browser.

### Database Setup

1. Start the MySQL server.
2. Open MySQL Workbench or another MySQL client.
3. Execute the project's database schema SQL file.
4. Load the sample data SQL file, if provided.
5. Configure database credentials using the application's documented configuration method.

### Application Setup

If the project uses Python and Flask:

1. Open the application folder in VS Code.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt`.
4. Configure the MySQL connection.
5. Run the application's documented entry-point file.
6. Open the local URL displayed by Flask in your browser.

Refer to the actual application files and setup instructions before running these steps.
